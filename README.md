# Tracer

A free tracing app for Android. Pick any photo, see it semi-transparent over your phone camera, and copy it onto paper.

- Unlimited photos, no ads, works fully offline, photos never leave your phone
- Opacity slider, drag, pinch to zoom, two-finger rotate
- Lock, flip, grid (3x3 to 8x8), Color / Gray / Outline modes
- Camera or white background (use white to trace through thin paper on the screen)
- Screen stays on while you draw

## Build

Push this project to GitHub. The workflow in `.github/workflows/build.yml` builds the APK
automatically. Download `Tracer.apk` from the **Releases** page (or **Actions** > latest run > Artifacts).
